# 🚀 Installation Guide

Follow these steps to install HostPilot.

---

## Step 1 — Clone Repository

```
git clone https://github.com/ranjanarnav/HostPilot.git 
cd HostPilot
``` 

---

## Step 2 — Install Dependencies

```
pip install -r requirements.txt  
```

---

## Step 3 — Create .env File

Copy:

```
cp .env.example .env  
```

Then edit the .env file and add:

- Discord Token  
- Pterodactyl API Key  

---

## Step 4 — Run HostPilot

```
python bot.py  
```

Your bot should now be running.
