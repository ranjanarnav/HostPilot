# 🛠️ Troubleshooting

Common issues and fixes.

---

## Bot Not Starting

Check:

- Python version is 3.9+  
- .env file exists  
- Dependencies installed  

---

## API Errors

Make sure:

- Pterodactyl API key is valid  
- Panel URL is correct  

---

## Permission Errors

Verify:

- Role ID is correct  
- Bot has required permissions
