# ⚙️ Configuration Guide

HostPilot uses environment variables stored in the .env file.

---

## Required Variables

DISCORD_TOKEN=your_token  
ALLOWED_ROLE_ID=role_id  

MONEY_LOG_CHANNEL_ID=channel_id  
REPORT_CHANNEL_ID=channel_id  

PTERO_PANEL_URL=https://panel.url  
PTERO_API_KEY=your_api_key  
PTERO_ALLOCATION_ID=123  

TIMEZONE=Asia/Kolkata  

Make sure all values are correct before starting the bot.
