## 🎯 What is HostPilot?

HostPilot is a modular Discord-based hosting automation system that allows administrators to control servers, automate tasks, log payments, and manage infrastructure from Discord.

---

## 🚀 Key Features

- Pterodactyl server management
- Hosting automation
- Money logging
- Scheduled tasks
- PDF report generation
- Status monitoring
- Role-based access control
