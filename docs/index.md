# <img src="../assets/icons/server-solid.png" width="26" /> What is HostPilot?

HostPilot is a **modular Discord-based hosting automation system** designed to simplify infrastructure management and operational workflows.

It enables administrators to control servers, automate tasks, log transactions, and manage hosting infrastructure directly from Discord.

---

HostPilot provides a comprehensive set of tools for managing hosting environments.

* Pterodactyl server management
* Hosting automation workflows
* Financial transaction logging
* Scheduled task execution
* PDF report generation
* Server status monitoring
* Role-based access control
